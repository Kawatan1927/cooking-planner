## アーキテクチャ概要

```mermaid
graph TD
    A[ブラウザ / SPA] -->|HTTPS| B[CloudFront]
    B -->|静的ファイル| C[S3]
    B -->|API リクエスト| D[API Gateway]
    D --> E[Lambda]
    E --> F[DynamoDB]
    A -->|認証| G[Cognito]
```

## 技術スタック

- **フロントエンド**: React + TypeScript (Vite)
- **バックエンド**: AWS Lambda (Node.js + TypeScript)
- **データベース**: Amazon DynamoDB
- **認証**: Amazon Cognito
- **インフラ**: AWS CDK
