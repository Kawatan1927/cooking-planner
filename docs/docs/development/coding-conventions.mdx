## コーディング規約

### 共通方針

- TypeScript の厳格モード（`strict: true`）を有効化する。
- フォーマッターは Prettier、リンターは ESLint を使用する。
- 自動チェックは lefthook の Git フックと CI で担保する。

### Prettier 設定

| オプション      | 値                         |
| --------------- | -------------------------- |
| `semi`          | `true`（セミコロンあり）   |
| `singleQuote`   | `true`（シングルクォート） |
| `tabWidth`      | `2`                        |
| `trailingComma` | `"es5"`                    |
| `printWidth`    | `100`                      |
| `arrowParens`   | `"avoid"`                  |

設定ファイル: `frontend/.prettierrc` / `backend/.prettierrc`

### ESLint 設定

| 領域           | 設定ファイル                | 主なルールセット                                |
| -------------- | --------------------------- | ----------------------------------------------- |
| フロントエンド | `frontend/eslint.config.js` | TypeScript ESLint + React Hooks + React Refresh |
| バックエンド   | `backend/eslint.config.mjs` | TypeScript ESLint + Prettier 競合ルール無効化   |

### フロントエンド固有のルール

- API 呼び出しは `src/lib/apiClient.ts` 経由で行う。
- エンドポイント単位の API ラッパーは `src/features/<domain>/api/` に置く。
- サーバー状態は React Query のカスタムフックで管理する。
- 機能追加は `src/features/<domain>/` に配置する。

### バックエンド固有のルール

- ルーティングは Hono の宣言的ルーターで定義する。
- `userId` は Cloudflare Access JWT または `DEV_USER_ID` から取得する。
- PostgreSQL 操作は repository 層に集約する。
- `recipes` / `menus` のクエリは必ず `user_id` でスコープする。
- エラーレスポンスは `docs/04-api-design.md` の形式に従う。

## ドキュメント記法ルール

Docusaurus（MDX）で書くドキュメントの統一ルールです。

### Frontmatter 標準

すべての `.md` / `.mdx` ファイルの先頭に以下の Frontmatter を記載します。

```yaml
---
id: <ファイル名と同じ kebab-case の識別子>
title: <日本語のページタイトル>
sidebar_position: <カテゴリ内の並び順（数値）>
---
```

### 見出し規約

- `# H1` はページタイトルとして Frontmatter の `title` が担うため、本文中では使わない。
- 最上位見出しは `## H2` から始める。
- 見出しは意味的な階層に従い、レベルを飛ばさない。

### コードブロック規約

コードブロックには必ず言語識別子を付けます。

````mdx
```bash
bun install
```

```ts
const foo: string = "hello";
```

```yaml
key: value
```
````

### Admonition 利用方針

| 種別         | 用途                         |
| ------------ | ---------------------------- |
| `:::note`    | 補足情報・背景説明           |
| `:::tip`     | 推奨の操作・ショートカット   |
| `:::info`    | 参照先・関連情報の案内       |
| `:::warning` | 注意が必要な操作             |
| `:::danger`  | データ損失・破壊的変更の警告 |

### カテゴリ

新しいカテゴリディレクトリを作成する際は `_category_.json` を配置します。

```json
{
  "label": "カテゴリ名（日本語）",
  "position": 5,
  "link": {
    "type": "generated-index"
  }
}
```
