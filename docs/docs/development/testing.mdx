## 現状

バックエンドにはテストがあり、リポジトリルートの `bun run test` から実行します。フロントエンドのテストは必要に応じて今後追加します。

## テスト実行コマンド

```bash
# リポジトリ全体
bun run test

# バックエンドのみ
bun run backend:test
```

## 今後の方針

### フロントエンド

- フレームワーク候補: Vitest
- 優先度:
  1. ユーティリティ関数・ビジネスロジック
  2. カスタムフック
  3. 重要なコンポーネント

### バックエンド

- Hono handler のユニットテストを優先する。
- repository 層は PostgreSQL との境界を明確にし、必要に応じて DB を分離して検証する。
- 認証まわりは `DEV_USER_ID` と Cloudflare Access JWT 検証の両方を確認する。

## CI との連携

テストを追加した場合は、関連する CI ワークフローと lefthook の `pre-push` フックも更新してください。
