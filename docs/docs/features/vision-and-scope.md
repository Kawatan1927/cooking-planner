## プロダクト概要

Cooking Planner は、料理本ベースのレシピを献立と買い物リストまで一気通貫で管理する個人専用 Web アプリです。

- 書籍に載っているレシピをデータとして登録する。
- 日付ごとに朝・昼・夜の献立を決める。
- 複数日の献立から必要な材料をまとめて買い物リストとして取得する。
- インターネット上に公開するが、Cloudflare Access で認証した自分だけが利用できる。

## ゴール

- レシピ本のレシピを登録・編集・閲覧できる。
- 日付と食事区分ごとに献立を登録できる。
- 指定期間の献立から材料の総量を算出し、買い物リストとして表示できる。
- スマホから買い物リストへアクセスできる。
- Cloudflare Access により、認証済みの自分以外は利用できない。

## 非ゴール

- 一般公開サービス化
- 複数ユーザーが自由にサインアップする仕組み
- レシピ手順のリッチな管理
- レシピ画像アップロード
- 栄養計算・カロリー計算
- 店舗別最適化や価格比較
- 他サービスとの連携・スクレイピング
- 多言語対応

## MVP 範囲

### Must

- レシピ管理
  - レシピの新規登録・編集・一覧表示・詳細表示
  - レシピに紐づく材料の登録・編集
- 献立管理
  - 日付＋食事区分ごとのメニュー登録・閲覧
  - メニューに紐づくレシピ選択と対象人数の指定
- 買い物リスト
  - 任意期間の献立から材料を集計
  - 材料名ごとに必要量を集約
  - スマホから閲覧できるチェックリスト UI
- 認証
  - Cloudflare Access によるアクセス制御
  - Cloudflare Access を通過したリクエストのみ API にアクセス可能
- 公開
  - Cloudflare Tunnel によるインターネット公開
  - HTTPS は Cloudflare 側で終端

### Should

- 材料カテゴリ管理
- 常備品フラグ
- レシピのメモ欄

### Won't

- マルチテナント・本格的なユーザー管理
- レシピのインポート機能
- PWA 対応・オフライン対応
- 通知・リマインダー機能

## 技術的スコープ

### フロントエンド

- Vite + React + TypeScript の SPA
- React Router によるクライアントサイドルーティング
- TanStack Query によるサーバー状態管理
- Hono server が静的ファイルとして配信

### バックエンド / インフラ

- Bun + Hono
  - ローカル PC 上で常時起動
  - API と静的ファイル配信を担う小規模モノリス構成
- PostgreSQL
  - ローカル PC 上で起動
  - `recipes`, `recipe_ingredients`, `menus` などのテーブルを管理
- Cloudflare Tunnel
  - ローカル PC の Hono server をインターネットに公開
  - HTTPS 終端は Cloudflare 側で処理
- Cloudflare Access
  - Zero Trust によるアクセス制御

## 非機能要件

- 個人利用のため、大量トラフィックは想定しない。
- 数十〜数百件のレシピ／献立をストレスなく扱えることを目安にする。
- ローカル PC 起動のため、PC 再起動やスリープ後の復帰に伴うダウンタイムは許容する。
- 外部アクセスには Cloudflare Access 認証を必須にする。
- Hono server の標準出力で最低限のログを確認できるようにする。
